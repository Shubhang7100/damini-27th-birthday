A LETTER TO DAMINI — 27TH BIRTHDAY WEBSITE

1. Extract this ZIP.
2. Create a GitHub repository, e.g. damini-27th-birthday.
3. Upload index.html and the entire photos folder to the repository root.
4. Open Settings > Pages.
5. Choose Deploy from a branch, select main and /(root), then Save.
6. The website URL will be:
   https://YOUR-USERNAME.github.io/damini-27th-birthday/

Keep the photos folder beside index.html.
